## 확인 범위

- AI Hub 소개·라벨 설명과 로컬에 받은 데이터의 범위·스키마를 확인했다. 실제 고용계약 점검 범위는 [[09 실제 데이터와 법령 API 점검]]에 있으며, 개별 이용·재배포 조건은 별도로 기록해야 한다.
- 모델 카드와 학습 라이브러리 문서를 확인했다. 이 저장소에서 모델 다운로드·학습·성능 측정은 실행하지 않았다.
- 법령 4종의 목록·본문을 실제 조회해 이름·ID·시행일을 대조했다. 개별 쟁점의 적용 조건·법률 판단 정답을 확정한 상태는 아니다.
- 문서의 샘플 JSON·처리 흐름·일정·목표 점수는 권리ON 구현을 위한 제안이다.
