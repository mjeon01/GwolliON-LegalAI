# 권리ON 로컬 계약 검토 플랫폼

사용자가 만든 조각상과 물리 기반 저울 애니메이션을 화면 전체 배경으로 확장하고 기존 FastAPI 기능을 연결했습니다. 차콜·실버 바탕에 블루 포인트를 사용합니다. 메뉴를 누르면 별도 URL로 이동하는 구조이며 메인화면은 `/`입니다.

영문 제목은 Space Grotesk 700, 한글 제목은 Pretendard 800, 본문은 Pretendard 500–600을 사용합니다. 폰트는 빌드에 포함되어 외부 CDN 없이 로컬에서 제공됩니다. 제목과 본문, 입력창의 글자 크기를 키우고 모바일에서는 세로로 배치합니다.

## 실행

프로젝트 루트에서:

```bash
./run_app.sh
```

http://127.0.0.1:8020 에서 메인화면을 엽니다. 스크립트는 필요한 프런트엔드 의존성을 설치하고 화면을 빌드한 뒤 FastAPI를 시작합니다. Python 환경과 `requirements.txt` 설치가 선행되어야 하며 Node.js 20.19 이상을 권장합니다.

UI를 개발할 때는 백엔드를 위 명령으로 실행한 뒤, 별도 터미널에서:

```bash
cd frontend
npm ci
npm run dev
```

http://127.0.0.1:5173 을 엽니다. `/api` 요청은 8020의 백엔드로 프록시하며 요청 Host를 유지해 같은 출처 검증이 동작합니다. 정적 파일을 직접 열거나 `npm run preview`만 실행하면 백엔드 기능은 연결되지 않습니다.

## 페이지와 범위

| URL | 용도 |
| --- | --- |
| `/` | 권리ON 메인, 검토 시작, 샘플 진입 |
| `/upload/` | TXT·PDF·이미지 읽기, 원문 수정, 계약 종류와 본인 입장 선택 |
| `/samples/` | 가상 인물의 계약서 5종 선택, PDF·PNG 저장, 한국어·중국어·스페인어 소개 |
| `/review/?id=…` | 실제 문서 위 번호·색 표시(`components/DocumentReview.jsx`), 옆 설명 카드와 양방향 이동, 검토 범위 |
| `/chat/?id=…` | 선택한 조항 해설·수정 제안과 자유 질문 |
| `/draft/?id=…` | 상담 요청문·계약 수정 요청서·검토 요약·사실확인 요청문 생성, 조항 선택, 빈칸 안내, 미리보기·편집, 복사, PDF 저장 |
| `/history/` | 최근 50개 검토 기록 검색, 이어서 작업, 삭제 |
| `/original/?id=…&block=…` | 검토에 사용한 원문, 선택한 문구 강조 |
| `/sources/?id=…&finding=…` | 법령·근거 자료 확인 |
| `/confirm/?id=…` | 추가 사실 입력 후 결과 갱신 |

질문·문서 페이지를 계약서 선택 없이 열면 기록 선택 화면을 보여줍니다. 검토·질문·문서 페이지 간에는 계약서 ID가 이어집니다. 일반 링크와 서버의 페이지 경로로 뒤로가기, 새로고침, 직접 접근을 지원합니다.

현재 `src/config/features.js`의 `CLOUD_AI_ENABLED=false`로 클라우드 선택·안내를 숨깁니다. 검토 내용과 챗봇 답변의 다국어 번역은 로컬 Ollama로 제공합니다. 검토는 규칙, 사진은 로컬 OCR, 자유 질문은 Ollama로 요청합니다. 이전 탭에 OpenAI 선택이 저장돼 있어도 로컬 설정으로 전송합니다. 기존 서버의 원문·인용·당사자 의무 검증을 유지합니다.

헤더의 언어 선택은 메뉴·안내·상태·오류·샘플 소개를 바꾸고 유지됩니다. 챗봇은 화면에서 선택한 언어를 요청에 전달하며, Qwen으로 질문을 한국어로 해석하고 검증된 답변을 다시 번역합니다. 기존 대화도 선택 언어로 바뀌고 한국어 답변은 펼쳐 확인할 수 있습니다. 사건 경위·문서는 한국어로 사용합니다. 클라우드 기능을 다시 활성화하면 검토 결과의 선택 언어 설명은 `/translations`에서 실제 검토 내용으로 생성합니다. 계약서·법령 인용은 한국어를 보존합니다. 한국어로 생성한 문서를 편집한 뒤 번역을 갱신하며, 현재 편집본과 일치하는 번역만 두 언어로 복사·저장할 수 있습니다.

사진은 5장 미리보기·회전·삭제·앞뒤 순서 변경 후 읽습니다. 사진과 페이지별 추출문을 대조하며 실패·판독 불가 페이지를 수정하고 확인해야 검토할 수 있습니다. 사진 선택이 바뀌면 다시 읽어야 합니다.

질문은 `/chat/stream`의 SSE로 생성 상태를 받고, 검증된 답변을 타이핑 효과로 표시합니다. 서버는 Ollama의 NDJSON 스트림을 소비하지만 원문·근거·당사자 의무 검증 전 토큰은 노출하지 않습니다. 잘못된 첫 응답은 수정 후 검증하고, 완료된 대화만 저장합니다. 움직임 줄이기 설정에서는 타이핑 애니메이션을 생략합니다. 연결이 완료 직후 끊기면 저장된 대화를 복구해 중복 전송을 방지합니다.

## 저장과 구조

- 검토 결과와 대화는 기존 로컬 SQLite에 저장합니다. 추가 사실로 검토가 갱신되면 revision이 바뀌며 이전 버전 대화·초안을 섞지 않습니다.
- 입력 중 계약서, 자유 질문, 문서 초안은 브라우저 `sessionStorage`에 임시 저장합니다. 같은 탭에서 페이지 이동·새로고침 후 복원됩니다. 탭을 닫기 전 보관할 문서는 TXT로 저장하세요.
- `src/i18n/`: 언어 상태와 UI 번역 문구. `src/hooks/`: 데이터 조회·분석 폴링·임시 저장, 검토 및 대화 번역, 타이핑 효과.
- `src/App.jsx`: 페이지 선택과 공통 구조. `src/pages/`: 각 작업 화면. `src/lib/`: API, URL, 저장, PDF 다운로드와 SSE 처리. `src/config/`: 기능 설정. `src/components/UI.jsx`: 메뉴와 공통 UI.
- `src/styles/global.css`: 공통 폰트·색상, 메뉴와 전체 배경 Hero 스타일. `src/styles/workspace.css`: 기능 화면 레이아웃과 입력·결과 UI.
- `JusticeStatue.jsx`와 원본 WebP 레이어의 물리 애니메이션은 유지했습니다. 아이콘으로 표시되는 움직임 정지 버튼과 `prefers-reduced-motion` 대응을 추가했습니다.
- `npm run build` → `dist/`. FastAPI가 이 빌드와 `/assets`를 제공합니다. 빌드가 없으면 `./run_app.sh` 실행을 안내합니다.

## 검증

```bash
npm run build
npm run test:i18n
npm exec playwright install chromium
npm run test:e2e
# 프로젝트 루트
.venv/bin/python -m unittest discover -s tests -p 'test_*.py' -q
```

브라우저 자동 검증은 Chromium의 1440px와 375px에서 실행합니다. 사진 등록·회전·순서 변경·삭제·원문 확인 → 검토 → 중국어·스페인어 질문·답변과 기존 대화의 언어 전환 → 한국어 사건 경위 → 문서 편집·한국어 TXT 다운로드를 포함합니다. 언어 유지, 오류 후 입력 보존, 개별 페이지 직접 접근과 가로 넘침도 검사합니다.

`tests/browser_server.py`는 별도 8021 포트·임시 DB·모의 로컬 OCR·Ollama만 사용하고 클라우드 호출은 실패시킵니다. 실제 사용자 DB나 키를 사용하지 않습니다. 자동 테스트 결과는 실모델의 판독·번역 품질 검증과 구분해야 합니다.
